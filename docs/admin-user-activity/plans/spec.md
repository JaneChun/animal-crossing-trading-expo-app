# 어드민 유저 상세: 신고·리뷰·차단 내역과 정지 상태 - 명세

## 화면/기능 흐름

### 유저 상세(`AdminUserDetail`)

- 활동 섹션 다음 순서는 거래 리뷰 → 신고(받은 신고·보낸 신고) → 차단(차단함·차단당함)이다.
- 거래 리뷰 섹션 아래에 "리뷰 내역 보기 >" 링크를 둔다. 누르면 리뷰 내역의 "받은 리뷰" 탭이 열린다.
- 신고 섹션 아래에 "신고 내역 보기 >", 차단 섹션 아래에 "차단 내역 보기 >" 링크를 둔다. 각각 "받은 신고", "차단한 유저" 탭이 먼저 열린다.
- 정지 중이면 계정 섹션 바로 아래에 정지 해제 패널(`DangerActionPanel`)을 보여 준다. 정상 계정에는 별도 표시가 없다.

### 내역 화면(`AdminUserRecords`)

- 상단에 탭 두 개가 있고, 탭마다 최신순으로 20개씩 불러온다. 목록 끝에 닿으면 다음 20개를 불러온다.
- 신고 내역
  - 받은 신고: 이 유저가 피신고자인 신고(`reporteeId == uid`)
  - 보낸 신고: 이 유저가 신고자인 신고(`reporterId == uid`)
  - 행 모양과 동작은 신고 관리 목록과 같다. 누르면 신고 상세로 간다. 처리 상태와 관계없이 모두 보여 주고, 처리 완료 신고에는 "처리완료" 배지를 붙인다.
- 리뷰 내역
  - 받은 리뷰(`receiverId == uid`) / 보낸 리뷰(`senderId == uid`)
  - 행: 상대 유저(받은 리뷰는 작성자, 보낸 리뷰는 받은 사람)의 프로필 사진·닉네임·섬 이름, 그 아래 거래 게시글 제목 한 줄, 오른쪽에 작성 시각과 만족·불만족 얼굴 아이콘
- 리뷰·차단 행을 누르면 상대 유저의 어드민 유저 상세로 간다.
- 차단 내역
  - 차단한 유저(`Users/{uid}/BlockedUsers`) / 차단당한 유저(`Users/{uid}/BlockedBy`)
  - 행: 상대 유저 정보, 오른쪽에 차단 시각(`blockedAt`)
- 빈 목록 문구
  - "받은 신고가 없습니다." / "보낸 신고가 없습니다."
  - "받은 리뷰가 없습니다." / "보낸 리뷰가 없습니다."
  - "차단한 유저가 없습니다." / "이 유저를 차단한 유저가 없습니다."
- 조회 실패: 기존 `InfiniteList`처럼 "목록을 불러오지 못했습니다."를 보여 준다.

## 상태 정의

| 상태 | 설명 |
| --- | --- |
| 정상 계정 | `report`가 없거나 `report.suspendUntil`이 `null`이거나 이미 지난 시각 |
| 정지 계정 | `report.suspendUntil`이 현재보다 미래 |
| 차단한 유저 | 이 유저가 차단해서 `Users/{uid}/BlockedUsers`에 문서가 있는 상대 |
| 차단당한 유저 | 이 유저를 차단해서 `Users/{uid}/BlockedBy`에 문서가 있는 상대(함수 `blocking` 트리거가 기록) |

## 엣지 케이스

- 상대 유저가 탈퇴함: 기본 유저 정보(기본 닉네임·기본 프로필 사진)로 보여 주고, 행을 눌러도 이동하지 않는다.
- 같은 신고자가 같은 유저를 재신고함: 신고 문서는 하나로 덮어써지므로 목록에도 한 행이며, 시각은 마지막 신고 시각이다.
- 리뷰 `value`가 0(선택 안 함)인 문서: 얼굴 아이콘 없이 시각만 보여 준다.
- 숫자 통계와 목록 개수가 다름: 받은 리뷰·받은 신고 숫자는 유저 문서의 누적 값이라 실제 문서 수와 다를 수 있다. 목록은 실제 문서 기준이며 맞추지 않는다.
- 리뷰가 달린 게시글이 영구 삭제됨: 제목 줄을 그리지 않는다.
- 정지 기한이 지났지만 `suspendUntil` 값이 남아 있음: 정상 계정으로 보고 패널을 그리지 않는다(현재 시각과 비교).
- 내역 화면에서 다른 유저 상세로 들어감: 새 화면으로 쌓이고, 뒤로 가면 원래 내역 화면으로 돌아온다.
