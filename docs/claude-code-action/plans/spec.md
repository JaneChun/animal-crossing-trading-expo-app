# Claude Code Action 기반 PR 리뷰·@claude 작업 자동화 - 명세

## 화면/기능 흐름

- 자동 리뷰: master 대상 PR이 열리거나 갱신되고 draft가 아니면 → 공식 `code-review` 플러그인이 변경 사항을 검토하고, 검증된 문제는 해당 줄에 인라인 코멘트로, 문제가 없으면 요약 코멘트 하나를 남긴다. 모든 코멘트는 한국어로 작성한다.
- 리뷰 기준: 플러그인 기준을 따른다. 컴파일 실패, 명백한 로직 오류, 인용 가능한 CLAUDE.md 규칙 위반만 지적하고, 스타일·주관적 제안·lint로 잡히는 문제는 지적하지 않는다. 기존 프롬프트의 React Native·Firebase 체크리스트는 사용하지 않는다(CLAUDE.md 규칙으로 대체된다).
- 추가 작업: JaneChun이 PR 댓글, 인라인 리뷰 댓글, 리뷰 본문 중 하나에 `@claude`를 포함하면 → Claude가 진행 상황 코멘트를 남기고 요청을 수행한 뒤, 해당 PR 브랜치에 커밋을 푸시하고 코멘트에 결과를 갱신한다. 새 PR은 만들지 않는다.
- 추가 작업 중 검증: Claude는 `npm run lint`, `npm run typecheck`만 실행할 수 있다.

## 상태 정의

| 상태 | 설명 |
| --- | --- |
| 리뷰 스킵 | PR이 draft, closed이거나, 사소한 변경이거나, Claude가 이미 코멘트한 PR |
| 멘션 무시 | `@claude`가 없거나, 작성자가 JaneChun이 아닌 경우. 워크플로 잡 자체가 실행되지 않는다. |

## 엣지 케이스

- 같은 PR에 연속 푸시: 진행 중인 리뷰 실행은 취소되고 마지막 실행만 남는다.
- `CLAUDE_CODE_OAUTH_TOKEN` 미등록: 두 워크플로 모두 인증 단계에서 실패한다. 나머지 CI 잡에는 영향이 없다(별도 워크플로 파일).
- `@claude` 워크플로 파일이 master에 없을 때: 댓글 이벤트 워크플로는 기본 브랜치 기준으로 실행되므로, 머지 전에는 멘션해도 아무 일도 일어나지 않는다.
- Claude가 이미 리뷰한 PR에 새 커밋 푸시: 플러그인이 기존 Claude 코멘트를 감지해 재리뷰를 건너뛴다. 따라서 PR당 자동 리뷰는 사실상 한 번이다.
