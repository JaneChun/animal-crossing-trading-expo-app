## QA 중 고친 것

- 입력칸 5곳(`SearchInput`, `NameInput`, 신고 상세, 프로필 칭호·한마디)에 글자색이 없어 다크에서 입력한 글자가 검정으로 나왔다 → `text.primary` 지정
- 프로필 여권 카드의 흰 섬 실루엣이 다크에서 글자를 가렸다 → RN `Image`의 `tintColor`로 카드 면 색(`bg.primary`)을 입힘. `react-native-fast-image`의 `tintColor`는 iOS에서 앱이 종료돼 쓰지 않는다
- 프로필 수정 시트 안쪽만 `bg.primary`여서 시트 가장자리에 띠가 생겼다 → `bg.elevated`
- 입력칸·칩·카드·받은 말풍선이 다크에서 바탕과 거의 같거나 더 어두웠다(대비 1.04~1.09) → 면 토큰 `bg.fill`(다크 `#24242E`)·`bg.raised`(다크 `#30303B`)를 추가해 24개 파일의 면을 옮김. 시트 안에서는 `SheetThemeProvider`가 `bg.fill`을 `#30303B`로 바꿈. 설정 카드의 행 구분선은 `border.onFill`(다크에서 화면 바탕색)로 바꿈. 시안: https://claude.ai/artifact/LXptWwTjD7Ninv9Zfqo9cH
