# Android 프로덕션 출시 대응 - 명세

## 화면/기능 흐름

### 로그인

- Android, 로그인 화면 진입 → `네이버로 로그인`, `Google로 로그인` 순서로 버튼을 표시한다. Apple 버튼과 Apple 가입자용 안내 문구는 표시하지 않는다.
- iOS, 로그인 화면 진입 → 지금과 동일하게 네이버·Apple 버튼을 표시한다. Google 버튼은 표시하지 않는다.
- Android, Google 버튼 탭 → Google 계정 선택 창이 열린다. 계정 선택 → 서버가 Google ID 토큰을 검증하고 커스텀 토큰으로 로그인한다.
- Android, 네이버·Google 로그인 성공 → 신규 유저는 약관 동의 화면, 기존 유저는 "로그인 성공" 토스트 후 내 프로필로 이동한다(iOS와 동일).
- Android, 네이버·Google 로그인 창에서 취소 → 오류 표시나 화면 이동 없이 로그인 화면에 머문다.
- 탈퇴 후 30일 이내에 같은 Google 계정으로 로그인 → 기존 소셜 로그인과 동일하게 재가입 제한 오류를 받는다.

### 계정 화면 (Google 가입자)

- 이메일 옆에 Google 아이콘을 표시한다.
- 로그아웃 → Firebase 로그아웃과 함께 Google 로그인 세션도 해제한다. 다음 로그인 때 계정 선택 창이 다시 열린다.
- 회원 탈퇴 → 네이버·카카오와 같이 재인증 화면(`SocialAccountCheck`)에서 Google 로그인을 한 번 더 거친 뒤 탈퇴 화면으로 이동한다. 탈퇴 완료 시 앱의 Google 접근 권한도 철회한다.

### 푸시 알림

- Android, 앱 첫 실행 → `default` 채널(시스템 설정에 표시되는 이름: `알림`)을 생성한 다음 알림 권한 팝업을 띄운다(Android 13 이상). Android 12 이하는 권한 팝업 없이 바로 허용 상태다.
- 권한 거부 → 기존과 동일하게 "푸시 알림 권한이 없습니다. 설정에서 권한을 허용해주세요." 토스트를 표시한다.
- 알림 수신(포그라운드) → 헤드업 알림으로 표시한다(`default` 채널 중요도 MAX).
- 알림 탭(포그라운드·백그라운드·앱 종료 상태 모두) → 알림 데이터의 `url`로 이동한다. 채팅 알림은 해당 채팅방, 댓글·답글 알림은 해당 게시글 상세.
- 상태바 알림 아이콘 → 제공받은 흰색 단색 아이콘을 지정 색상으로 표시한다.

### 알림 설정 토글 (프로필 > 설정)

- 토글 탭 → 양 플랫폼 모두 OS의 이 앱 설정 화면을 연다.
- 설정 화면에서 권한을 바꾸고 앱으로 복귀 → 토글 상태가 실제 권한 상태로 갱신된다(기존 `AppState` 재확인 로직).

### 사진 선택

- Android 13 이상, 사진 추가 버튼 탭 → 권한 팝업 없이 시스템 사진 선택기가 열린다.
- Android 12 이하, 사진 추가 버튼 탭 → 시스템 문서 선택기 또는 갤러리가 열린다. 저장소 권한을 요청하지 않는다.
- 카메라 촬영 → 양 플랫폼 모두 카메라 권한을 확인하고, 거부 시 기존 "카메라를 사용하려면 카메라 접근 권한이 필요합니다." 토스트를 표시한다.
- 여러 장 선택 시 선택 개수 제한과 선택 순서는 iOS와 동일하게 유지한다.

### 뒤로가기 (Android 하드웨어·제스처)

- 바텀시트가 열린 상태 → 뒤로가기는 시트만 닫는다. 화면은 이동하지 않는다.
- RN `Modal`(이미지 뷰어, 업데이트 모달 등)이 열린 상태 → 각 모달의 `onRequestClose` 동작을 따른다. 강제 업데이트 모달은 닫히지 않는다.
- 아무것도 열려 있지 않은 상태 → React Navigation 기본 동작(이전 화면, 루트에서는 앱 종료).

### 키보드

- 입력창 포커스 → 키보드와 전역 `KeyboardToolbar`("완료" 버튼) 위에 입력창이 보여야 한다. 대상 화면: 채팅방 입력창, 게시글 상세 댓글 입력창, 게시글 작성 폼, 닉네임·섬 이름 입력.
- 키보드 닫힘 → 입력 영역이 원래 위치로 돌아오고 빈 공간이 남지 않는다.

### 광고

- Android 개발 빌드 → Google 공식 Android 테스트 광고 단위를 사용한다.
- Android 프로덕션 빌드 → AdMob에서 발급한 Android 광고 단위를 사용한다. iOS 광고 단위를 요청하지 않는다.
- ATT(추적 권한) 팝업은 iOS에서만 표시한다(기존 동작).

### 업데이트 안내

- 앱 시작 시 현재 앱 버전이 해당 플랫폼의 최소 버전보다 낮으면 업데이트 모달을 표시한다. iOS는 `minimum_version`, Android는 `minimum_version_android`를 비교 기준으로 쓴다.
- `force_update`와 `update_message`는 두 플랫폼이 공유한다.
- Android에서 "업데이트" 탭 → `store_urls.android`의 Play 스토어 페이지를 연다.

### 화면 표시

- Android 시스템이 다크 모드여도 앱은 라이트 모드로 표시한다. 상태바 아이콘은 어두운 색이다.
- Android 12 이상 앱 실행 → 흰 배경 중앙에 앱 로고가 표시된 스플래시 후 앱 화면으로 넘어간다.
- 하단 내비게이션 바(3버튼·제스처)가 버튼·입력창을 가리지 않는다.

## 상태 정의

| 상태 | 설명 |
| --- | --- |
| 알림 권한 `undetermined` | Android 13 이상에서 아직 권한 팝업에 응답하지 않은 상태 |
| 알림 권한 `granted` | Android 12 이하 설치 직후, 또는 팝업에서 허용한 상태 |
| 알림 권한 `denied` | 팝업에서 거부했거나 시스템 설정에서 끈 상태. 토글은 꺼짐으로 표시 |
| 바텀시트 열림 | `CustomBottomSheet`의 `isVisible`이 true. 이 동안만 뒤로가기를 가로챈다 |

## 엣지 케이스

- iOS에서 Apple로 가입한 사용자가 Android에서 로그인 시도: Apple 버튼이 없어 로그인할 수 없다. uid가 소셜 계정 ID로 만들어지므로, 같은 이메일로 네이버·Google 로그인을 해도 별도 계정으로 생성된다.
- Android에서 Google로 가입한 사용자가 iOS에서 로그인 시도: iOS에는 Google 버튼이 없어 로그인할 수 없다.
- Google Play 서비스가 없거나 오래된 기기: Google 계정 선택 창이 열리지 않는다. 라이브러리 오류를 로그인 실패로 처리하고 앱이 종료되지 않아야 한다.
- `minimum_version_android` 필드가 없는 상태: 업데이트가 필요 없는 것으로 처리한다(기존 문서 없음 처리와 동일).
- 에뮬레이터에서 실행: `Device.isDevice`가 false라 푸시 토큰을 발급하지 않고 기존 토스트를 표시한다. 푸시 확인은 실기기에서만 한다.
- 네이버 앱 미설치 기기: 네이버 로그인이 웹 로그인 화면으로 진행되어야 한다.
- Play 스토어가 없는 기기(일부 중국 제조사 등)에서 업데이트 탭: `canOpenURL`이 https라 true를 반환하고 브라우저로 Play 스토어 웹페이지가 열린다.
- 메일 앱이 없는 기기에서 설정 > 문의하기 탭: `mailto:` 처리 앱이 없으면 `Linking.openURL`이 실패한다. QA에서 확인하고, 실패 시 안내 방식은 사용자에게 확인한다.
- 사진 선택 중 앱이 백그라운드에서 종료됨(Android 메모리 회수): 선택 결과가 유실될 수 있다. 크래시만 없으면 허용한다.
- 바텀시트 안 입력창에 포커스된 상태에서 뒤로가기: Android는 첫 번째 뒤로가기로 키보드가 먼저 닫히고, 두 번째 뒤로가기에서 시트가 닫힌다.
