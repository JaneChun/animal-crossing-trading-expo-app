# 공지사항 - 명세

## 화면/기능 흐름

### 목록 상단 공지 줄 (마켓 탭·커뮤니티 탭 공통)

- 게시 중 공지 1개 이상: 목록 첫 줄에 높이 44px 공지 줄 + 그 아래 화면 양끝까지 높이 8px `bg.secondary` 띠
- 공지 줄 내용: 왼쪽 `Badge`(tone `brand`, 확성기 아이콘 + '공지'), 오른쪽 제목 한 줄. 넘치면 말줄임. 날짜·순번 표시 없음
- 게시 중 공지 2개 이상: 4초마다 다음 공지가 오른쪽에서 들어오고 현재 공지가 왼쪽으로 나간다 (약 450ms, ease-in-out). 마지막 다음은 첫 공지로 같은 방향 이어서
- 공지 줄 탭 → 그 순간 보이는 공지의 상세로 이동
- 목록 스크롤 → 공지 줄도 목록과 함께 위로 올라가 사라짐
- 당겨서 새로고침 → 거래글과 함께 공지도 다시 조회
- 탭 재진입·앱 재실행 → 다시 조회한 결과 반영. 실시간 반영은 하지 않음
- 노출 순서: `createdAt` 최신순
- 로그인 여부와 상관없이 보임
- 커뮤니티 탭: 카테고리 칩(고정) 아래, 첫 게시글 위. 카테고리를 바꿔도 공지는 그대로
- 내 프로필의 작성 글 목록, 검색 결과에는 공지 줄이 없음

### 공지 상세

- 진입: 공지 줄 탭으로만 들어온다
- 헤더: 가운데 '공지사항', 왼쪽 뒤로가기
- 본문 영역 순서: 제목(`title`, bold) → 작성일(`2026년 11월 15일` 형식, caption, `text.tertiary`) → 구분선(`border.default`) → 본문(`body1`, 입력한 줄바꿈 유지)
- 본문 URL(`http://`, `https://`로 시작): `text.primaryBrand` 색 + 밑줄. 탭 → 외부 브라우저 또는 해당 앱(Play 스토어 등)으로 열림
- 잎 배경: 화면 오른쪽 아래, 너비 약 500px, 오른쪽으로 일부 잘림, -12도 회전. 본문을 스크롤해도 화면에 고정. 탭·스크린리더 대상 아님

### 어드민 공지 관리

- `AdminHome` '운영' 섹션 '공지 관리' 행 탭 → 공지 관리 목록
- 목록: '게시 중' / '숨김' 두 탭. 각 행은 제목과 작성일, `createdAt` 최신순
- 행 탭 → 해당 공지 수정 화면
- 헤더 오른쪽 작성 버튼 탭 → 새 공지 작성 화면
- 작성·수정 화면: 제목 입력, 본문 입력, '숨기기' 체크박스, 저장 버튼
  - 새 공지: 체크박스 해제 상태로 시작 → 저장하면 바로 게시 중
  - 체크 = 숨김, 해제 = 게시 중. 저장해야 반영
  - '숨기기' 체크박스는 라벨만 있고 별도 안내 문구는 없다
  - 저장 성공 → 토스트('공지가 작성되었습니다.' / '공지가 수정되었습니다.') 후 이전 화면으로 돌아감. 목록·마켓·커뮤니티 데이터는 무효화되어 다시 조회
  - 저장 실패 → 오류 토스트('공지 작성 중 오류가 발생했습니다.' / '공지 수정 중 오류가 발생했습니다.'), 입력 내용 유지, 화면 유지
- 삭제 기능 없음

## 상태 정의

| 상태 | 설명 |
| --- | --- |
| 게시 중 | `hidden == false`. 마켓·커뮤니티 공지 줄에 노출, 어드민 '게시 중' 탭에 표시 |
| 숨김 | `hidden == true`. 유저에게 보이지 않음(읽기 규칙으로도 차단), 어드민 '숨김' 탭에 표시 |
| 공지 줄 없음 | 게시 중 공지 0개, 첫 조회 중, 조회 실패 중 하나 |
| 고정 표시 | 게시 중 공지 1개. 전환 애니메이션 없음 |
| 자동 전환 | 게시 중 공지 2개 이상 |
| 저장 중 | 작성·수정 저장 요청 중. 저장 버튼 비활성 |

## 엣지 케이스

- 공지 조회 중: 공지 줄 자리를 비워 둔다(스켈레톤 없음). 거래글 목록의 기존 로딩 스켈레톤은 그대로
- 공지 조회 실패: 공지 줄을 그리지 않는다. 오류 알림(Alert)도 띄우지 않는다 — 거래글 목록 사용을 막지 않기 위해
- 상세 진입 후 공지가 숨김·삭제되어 조회 결과 없음: '찾을 수 없음' 안내(`EmptyIndicator`)
- 관리자가 숨긴 공지를 유저가 앱에서 아직 보고 있음: 다음 조회 전까지 공지 줄에 남을 수 있다. 상세로 들어가면 규칙에 막혀 '찾을 수 없음'
- 관리자 계정의 상세 화면: 숨긴 공지도 열린다 (읽기 규칙이 관리자에게 허용)
- 자동 전환 중 화면이 포커스를 잃음(다른 탭·상세로 이동): 전환을 멈추고, 돌아오면 이어서 전환
- 자동 전환 중 공지 개수가 바뀜(새로고침 결과): 첫 공지부터 다시 시작
- 제목이 매우 긺: 공지 줄은 한 줄 말줄임, 상세에서는 여러 줄로 전부 표시
- 본문에 URL이 아닌 `www.` 형식만 있음: 링크로 인식하지 않는다
- 잘못된 URL 탭으로 `Linking.openURL` 실패: 아무 일도 일어나지 않게 조용히 무시한다
- 폼 검증: 제목 1~50자, 본문 1~3000자. 오류 문구는 게시글 폼과 동일
- 다크 모드: 모든 색은 테마 토큰. 잎 배경 불투명도는 라이트보다 낮게
